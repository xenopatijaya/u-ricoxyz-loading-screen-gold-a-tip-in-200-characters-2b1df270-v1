One sharp, funny loading-screen tip for stressed developers and AI coding agents, 200 characters or fewer. The program writes it to `/output/entry.txt`:

> Tip: Your agent didn't misunderstand your prompt. It understood it perfectly — and did the other thing anyway.

110 characters, one line, deterministic — the same bytes on every run.

## Why this tip

It is a real tip (not a slogan or status line), it earns the laugh with a turn — "understood it perfectly" flipping into "did the other thing anyway" — it lands in a glance, it speaks to the developer and the agent at once, and it is fresh: no coffee, deadline, or compile joke, and no rerun of the field's crowded "bar at 99%", "rewrote the file", or "deleted the tests" lines (checked against all 957 entries before submitting).

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
